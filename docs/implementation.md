# 玄機 (Xuanji) — 預測功能實現機制

## 概覽

玄機是一個基於 AI 的中國傳統預測網站，支持六種預測類型。核心理念是「程序排盤 + AI 解盤」——凡是可以通過固定規則計算的部分，由程序自動完成；需要靈活解讀和分析的部分，交由大語言模型 (LLM) 完成。

### 技術架構
- 前端：Next.js 14 (TypeScript)
- 後端：Next.js API Routes
- 數據庫：PostgreSQL + Prisma ORM
- AI：通過 OpenRouter API 調用不同等級的模型
- 部署：Docker (端口 8094)

## 一、八字命理 (BaZi / 四柱推命)

### 實現機制：程序排盤 + LLM 解盤

八字是六種預測中實現最深的一種，採用「雙重保障」模式：

#### 第一步：程序自動排盤（不依賴 LLM）

使用 `baziCalculator.ts` 模組（436行 TypeScript），基於 `lunar-typescript` 庫 + 自建查找表完成以下計算：

**四柱計算：**
- **年柱**：以立春為年界（非農曆正月初一），通過 `lunar-typescript` 的 `Solar` 類精確計算
- **月柱**：以24節氣中的12「節」劃分月份，月干由年干推算（五虎遁月口訣）
- **日柱**：由 `lunar-typescript` 的天文算法精確計算
- **時柱**：先通過真太陽時校正（見下），再由日干推算時干（五鼠遁時口訣）

**真太陽時校正（`trueSolarTime.ts`）：**
```
真太陽時 = 標準時間 + 經度時差 + 均時差(EoT)
經度時差 = (當地經度 - 120°) × 4分鐘/度
均時差 = 9.87×sin(2B) - 7.53×cos(B) - 1.5×sin(B)
其中 B = (360/365) × (日序 - 81) × (π/180)
```
- 內置44個中國主要城市經緯度查表
- 自動判斷校正後是否跨越時辰邊界（如巳時→午時），若有變化會在結果中提示

**附加計算（全部程序化）：**
- **地支藏干**：每個地支內含的天干（主氣/中氣/餘氣），含權重計算（主氣0.6, 中氣0.3, 餘氣0.1）
- **十神關係**：以日主為基準，計算每個天干的十神（比肩/劫財/食神/傷官/偏印/正印/偏財/正財/七殺/正官）
- **五行統計**：統計四柱所有天干+藏干的五行分佈（含藏干權重）
- **納音**：完整60甲子納音對照表（海中金、爐中火等）
- **日主強弱**：基於令（月令生扶）、根（地支藏干）、印比數量綜合判斷
- **喜用神/忌神**：根據日主強弱推算
- **神煞**：天乙貴人、文昌、驛馬、桃花、華蓋、將星、劫煞、亡神、天德、月德（共10種）

#### 第二步：LLM 校驗 + 深度解讀

將程序計算的完整命盤數據以 JSON 格式發送給 LLM，prompt 要求：
- 校驗程序計算結果，如有明顯錯誤則糾正
- 基於命盤數據進行深度解讀分析
- 填寫六個分析區塊：總覽、事業、婚姻、財運、健康、大運流年（每項100+字）
- 提供核心建議和吉數/吉色/吉方

**LLM 的角色是「解盤」而非「算盤」——排盤由程序保證精確性，解讀由 AI 發揮分析能力。**

#### 結果展示
- 四柱命盤視覺卡片（天干+十神+地支+藏干+五行+納音）
- 真太陽時校正信息欄
- 五行分佈柱狀圖
- 喜用神/忌神標籤
- 神煞列表（含懸停說明）
- 六個解讀分頁（Tab切換）
- 核心建議卡片
- 吉數/吉色/吉方

## 三、紫微斗數 (Zi Wei Dou Shu)

### 實現機制：程序排盤（iztro）+ LLM 解盤

紫微斗數採用與八字相同的「程序排盤 + AI 解盤」模式。

#### 第一步：程序自動排盤（iztro 庫）

使用 `ziweiCalculator.ts` 模組，基於開源 `iztro` 庫完成以下計算：

**排盤計算（全部程序化）：**
- **命宮/身宮定位**：由農曆出生月、時辰精確推算命宮地支，再定身宮
- **五行局**：根據命宮天干地支推算（金四局/木三局/水二局/火六局/土五局）
- **十四主星安放**：紫微星系（紫微、天機、太陽、武曲、天同、廉貞）+ 天府星系（天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍）
- **輔助星安放**：六吉星（文昌、文曲、左輔、右弼、天魁、天鉞）+ 六煞星（擎羊、陀羅、火星、鈴星、地空、地劫）+ 雜耀
- **四化飛星**：根據年干自動推算化祿、化權、化科、化忌
- **星耀亮度**：根據星曜所在宮位地支自動判定（廟/旺/得/利/平/閒/陷）
- **大限排列**：每宮十年大限，根據陰陽男女定順逆

**輸入：**
- 公曆出生日期（自動轉換農曆）
- 出生時辰（地支）
- 性別

**輸出數據結構 (`ZiweiChart`)：**
- `palaces[]`：12宮完整數據（宮名、天干地支、主星、輔星、雜耀、亮度、四化、大限）
- `siHua[]`：四化飛星匯總（哪顆星化什麼，落在哪個宮）
- `fiveElementsClass`：五行局
- `soul`/`body`：命主/身主

#### 第二步：LLM 解盤

將程序排出的完整命盤 JSON 發送給 LLM，要求：
- 直接使用程序排盤數據，不自行重新排盤
- 分析命宮主星格局、四化影響、三方四正
- 為每個宮位撰寫分析文字
- 填寫四個分析區塊：總覽、事業、婚姻、財運

#### 結果展示

- **命盤資訊欄**：農曆日期、干支、五行局、命主/身主
- **四化飛星標籤**：化祿(綠)/化權(藍)/化科(黃)/化忌(紅)
- **傳統4×4命盤格**：十二宮按地支位置排列（巳午未申/辰酉/卯戌/寅丑子亥），中央顯示五行局信息
  - 每宮顯示主星（含亮度/四化標記）、輔星、大限年齡
  - 命宮特殊標記，身宮標注「身」
  - 點擊宮位展開詳細分析
- **四個解讀分頁**（Tab切換）
- **核心建議卡片**
- **吉數/吉色/吉方**

## 四、奇門遁甲 (Qi Men Dun Jia)

### 實現機制：程序排盤（taobi）+ LLM 解盤

奇門遁甲採用「程序排盤 + AI 解盤」模式。

#### 第一步：程序自動排盤（taobi 庫）

使用 `qimenCalculator.ts` 模組，基於開源 `taobi` 庫（GitHub: Taogram/taobi）完成以下計算：

**排盤計算（全部程序化）：**
- **陰陽遁判斷**：根據節氣自動判斷陽遁/陰遁（冬至後→夏至前為陽遁，夏至後→冬至前為陰遁）
- **局數推算**：由節氣+時辰自動推算用局（陽遁一局~九局 / 陰遁一局~九局）
- **天盤九星**：天蓬、天芮、天沖、天輔、天禽、天心、天柱、天任、天英按規律飛布九宮
- **人盤八門**：休門、死門、傷門、杜門、開門、驚門、生門、景門按地盤分布
- **神盤八神**：值符、螣蛇、太陰、六合、白虎、玄武、九地、九天按值符基準分布
- **天地盤天干**：六儀三奇（戊己庚辛壬癸 + 乙丙丁）在天盤和地盤的分布
- **值符值使**：自動推算當前旬首對應的值符（星）和值使（門）
- 基於 VSOP87D 天文算法精確計算太陽位置以確定節氣

**輸入：**
- 起局時間（默認當前時間，或用戶指定時間）

**輸出數據結構 (`QimenChart`)：**
- `grid[][]`：3×3 九宮格數據（每宮含星、門、神、天地盤天干）
- `palaces[]`：九宮平鋪數組
- `zhiFu`/`zhiShi`：值符/值使
- `roundLabel`：局數描述（如「陽遁九局」）
- `year`/`month`/`day`/`hour`：四柱干支
- `solarTerm`：節氣

#### 第二步：LLM 解盤

將程序排出的完整九宮格數據 JSON 發送給 LLM，要求：
- 直接使用程序九宮數據，不自行重新排盤
- 分析各宮星門神組合的吉凶
- 判斷天盤與地盤天干的克應關係
- 確定問事宮和結果宮
- 填寫四個分析區塊：當前局勢、事態走向、最佳時機、行動策略

#### 結果展示

- **盤面信息欄**：干支、節氣、局數、值符/值使
- **3×3 九宮格盤面**：按洛書排列（4-9-2 / 3-5-7 / 8-1-6）
  - 每宮顯示八神（顏色標記）、八門（吉凶色標）、九星、天地盤天干
  - 點擊宮位展開詳細信息
- **格局要素卡片**：問事宮/結果宮/值符/值使/當值門
- **四個分析區塊**（手風琴展開）
- **吉時/吉方建議**
- **核心建議卡片**

## 額度與計費系統

### 雙模型架構

| | 標準模型 (Model 1) | 高級模型 (Model 2) |
|---|---|---|
| 當前配置 | anthropic/claude-3-5-haiku | anthropic/claude-sonnet-4 |
| 特點 | 速度快，成本低 | 更深度分析，質量更高 |
| Admin 可配置 | ✅ 可在後台修改模型名稱 | ✅ 可在後台修改模型名稱 |

### 免費用戶額度

| 模型 | 每日限額 |
|---|---|
| 標準模型 | **20 次/天** |
| 高級模型 | **2 次/天** |

### 付費用戶額度

| 模型 | 每日限額 |
|---|---|
| 標準模型 | **不限次數** |
| 高級模型 | **20 次/天** |

### 額度規則
- 每日限額以 UTC 日為窗口，每天 0:00 UTC 重置
- 管理員 (Admin) 不受任何限額限制
- 所有限額數值可在 Admin 後台實時調整
- 分享獎勵：用戶生成分享鏈接，被他人領取後雙方各獲得 **5 次標準模型** 額外次數（可累積，不隨每日重置消失）

### 分享系統
- 用戶可生成專屬分享鏈接
- 分享頁面包含風格化二維碼（金色太極主題）
- 支持一鍵分享到微信、WhatsApp、Telegram、X (Twitter)
- 被分享者需登入後領取，雙方各得獎勵

## 通用機制

### 參考資料系統
每種預測類型配有獨立的參考資料文件（`divination-refs/*.md`），作為 LLM 的 system prompt 知識庫注入，確保回答基於傳統命理知識而非模型臆斷。

### 結構化輸出
所有 LLM 輸出強制要求為 JSON 格式，配有類型專屬的 JSON Schema。前端根據類型路由到對應的可視化渲染組件，確保結果展示的專業性和一致性。

### 錯誤處理
- API 超時：120秒
- 餘額不足 (402)、認證失敗 (401)、頻率限制 (429)、服務錯誤 (502) 均有雙語錯誤提示
- LLM 返回非 JSON 時自動降級為 Markdown 渲染

### 等待動效
請求 LLM 期間顯示玄學主題載入動畫：
- 八卦符號環繞旋轉
- 太極金色脈衝光暈
- 卦辭語錄輪播（每3秒切換）
- 「天機正在運轉...」「卦象浮現中...」等提示文字
