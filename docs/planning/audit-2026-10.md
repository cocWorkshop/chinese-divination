## 1. Executive Summary

1. **Zero Regressions on Prior Fixes**: Concurrency race fixes A1-A6 and performance optimizations D1-D7 remain **fully intact** with file and line evidence (§3.2, §3.3).
2. **P0 Product Billing Leak**: Master proactive checkin/reflection turns unconditionally deduct 1 Karma credit per round (`master/route.ts:347`)—proactive system outreach inadvertently functions as an unannounced charge, automatically triggered by `MasterChatContext.tsx:984-1028` on returning users (Consolidated Finding PROD-1/B5).
3. **Paywalled Feature Free-Bypass**: The annual fortune feature implements zero server-side billing (client-enforced only via `/api/credits/consume`), with unlock state stored in `localStorage`. Issuing a direct POST request returns premium LLM interpretations for free (Consolidated Finding PROD-2/B1/B2, manually verified).
4. **Latent Account Takeover (ATO) Risk**: OAuth unconditionally links accounts by email without verifying `profile.email_verified` (`oauthAccountLinking.ts:80-127`). Currently mitigated because only Google is enabled (`auth.ts:72-80`), but `allowDangerousEmailAccountLinking: true` introduces vulnerability if providers with unverified email flows are added.
5. **Structural Funnel Disconnects**: Poster QR codes lack referral attribution codes (sharers receive zero referral grants, PROD-3); OAuth new users receive only 3 credits, insufficient for an initial 5-credit reading (PROD-4, `oauthAccountLinking.ts:135`); zero re-engagement loop—no lifecycle emails, push registration without backend dispatchers, and silent refund notifications (PROD-6).
6. **Design & Accessibility Debt**: Modals lack semantic `dialog` elements, zero focus trapping across the site, and unhandled Android hardware back buttons (collapsing the web history instead of closing overlays); inline i18n ternary usage expanded from 290 to **550 lines** (architectural regression, UX-12).
7. **Operational Vulnerabilities**: `deploy-local.yml` lacks rollback capabilities—failing containers continue serving traffic on healthcheck failure (HYG-1); `restore.mjs:179` invokes `prisma db push --accept-data-loss` (the exact anti-pattern behind the 2026-06 migration drift incident), and `backup.mjs:22` hardcodes production URLs (D5/D6).

## 4. HMI/GUI Design Audit (W8a)

### 4.1 Design Observations

**Design System & Tokens**:
- UX-1 (D2): Light mode uses a 470-line cascade of `!important` overrides across ~150 dark-first classes (`globals.css:135-589`).
- UX-2 (D3): Token naming and values drift from design specs (`--bg-primary` vs `--bg-abyss`).
- UX-3 (D3): `ThemeProvider` lacks a `system` mode preference option (`ThemeProvider.tsx:15-25`).

**User Flows**:
- UX-4 (D1): Poster modal lacks semantic dialog attributes (`role="dialog"`, `aria-modal`, focus trap, Escape key handling).
- UX-5 (D1): Homepage exploration prompt renders `cursor-pointer` but has no click handler (`page.tsx:453-460`).
- UX-6 (D2): Deprecated purple gradient blur blob persists on onboarding card (`start/page.tsx:454`).
- UX-7 (D2): Public share view manipulates DOM styles directly (`document.querySelector('nav')`); loader hardcodes Traditional Chinese for all locales.
- UX-8 (D2): Completion animation renders 36 full-screen ember particles; recommended to replace with lightweight Golden Ripple.
- UX-9 (D3): Delete action buttons in dashboard have small touch targets (`~24px` height).

**Accessibility & Mobile**:
- UX-10 (D1): Zero focus trapping across application modals.
- UX-11 (D2): Only 34 `aria-label` attributes across the application; icon buttons rely on `title`.
- UX-12 (D1): Inline i18n ternary usage expanded to **550 occurrences** despite guidelines.
- UX-13 (D1): Android hardware back button pops history rather than dismissing modal overlays.
- UX-14 (D2): Missing `viewport-fit=cover` export for iOS safe-area handling.
- UX-15 (D3): Long asynchronous operations use manual spinners instead of standardized promises.

### 4.2 Design Solutions Roadmap

1. **ModalShell Primitive (P0)**: Create a reusable shell encapsulating overlay, `role="dialog"`, `aria-modal`, Escape listener, focus trap, and safe-area padding. Resolve UX-4 and UX-10 across all modals.
2. **Android Hardware Back Button Contract (P0)**: Register `App.addListener('backButton')` in `NativeInitializer` to dismiss top overlays before navigating history. Resolve UX-13.
3. **i18n Circuit Breaker (P1)**: Configure ESLint rule `no-restricted-syntax` targeting inline `lang === 'en' ?` outside `src/lib/i18n`. Migrate remaining instances. Resolve UX-12.
4. **Semantic Token Refactoring (P1)**: Define semantic Tailwind tokens (`text-muted`, `bg-surface`) to eliminate 470 lines of light mode CSS overrides. Resolve UX-1 and UX-2.
5. **Route-grouped Public Share Pages (P1)**: Move `/r/[token]` into an isolated route group without global navigation bars, eliminating DOM manipulation. Resolve UX-7.
6. **Golden Ripple Micro-interaction (P2)**: Replace heavy 36-particle flame animations with hardware-accelerated CSS conic gradients. Resolve UX-8.

### 5.2 Funnel Drop-off Analysis

```
Ad Traffic -> /start -> Birth Form -> Init (10 Credits) -> Paipan Stream (5 Credits) -> Master Demo (1 Credit/turn)
           -> Credits Depleted -> Unlock Password -> Email Verification Wall -> Login -> Dashboard
```

1. **Email Verification Wall**: Mandatory logout immediately after registration causes significant abandonment if verification emails encounter delivery delays.
2. **Master Demo Depletion**: Trial credits reach zero during the initial conversational demo, creating friction before value is established.
3. **OAuth Activation Block**: OAuth users receive 3 credits, blocking them from their first 5-credit reading.
4. **Attribution Loss**: Public reading and poster referral traffic lack source attribution tags.

### 5.3 Quick Wins (<1 Day Each)

1. **Checkin Credit Exemption**: Guard `master/route.ts:347` with `!isCheckin && !isReflection`.
2. **Annual Fortune Server Billing**: Validate `decadesUnlocked` in `reading.result` on the server before generating analysis; clear localStorage fallback.
3. **Align OAuth Welcome Credits**: Match `registerBonus` ($\ge 6$ credits) to guarantee first reading completion.
4. **Unify Share Bonus Default**: Standardize fallback value to 5 across all three locations.
5. **Poster Referral Loop**: Pre-generate share tokens and attach `?ref=[shareCode]` to poster QR codes and registration links.
6. **Realistic Pricing Anchors**: Replace inflated strike-through pricing with legitimate volume package incentives.
7. **Transparent Refund Notices**: Write a `Notification` record when `markFailed` executes so users are aware of credit restorations.
8. **Enable Wiki Navigation**: Toggle `showWikiNav` to true in admin settings to activate SEO landing pages.

## 7. Decisions Required

1. **Next.js Critical Advisories**: 14.2.35 remains in the affected range for two critical DoS advisories. Recommend tightening `remotePatterns` and restricting Image Optimizer surfaces while scheduling a migration to Next.js 15.
2. **Playwright Integration**: Decide whether to remove Playwright from devDependencies or configure automated end-to-end tests for core user paths (Login, Paipan, Master).
3. **CreditLog Retention vs. GDPR**: Balance financial audit ledger retention with user data deletion requests. Recommend retaining pseudonymized transaction logs with personal identifiers redacted.
4. **Welcome & Referral Bonus Standardization**: Standardize fallback values across OAuth, registration, and referrals (recommend standardizing on 5 or 6 credits).
5. **Decadal Fortune Pricing Structure**: Determine whether 1-credit pricing for decadal unlocks is an intentional loss-leader or should be adjusted alongside premium packages.
6. **Master Checkin Billing Policy**: Confirm whether automated checkins should be strictly free across all user tiers.
