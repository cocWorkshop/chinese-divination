### 4.2 设计优化方案（按优先级）

1. **ModalShell 原语**（P0，S）：一个组件封装 overlay + `role="dialog"` + `aria-modal` + Escape + focus trap/return + safe-area padding；改造 FatePosterModal、start 跳过弹窗、MemoryGate、CacheDialog。一举消 UX-4/UX-10。

3. **i18n circuit-breaker**（P1，M）：ESLint `no-restricted-syntax` 对 `lib/i18n` 之外的 `lang === 'en' ?` 直接报错止血；再按 surface 分批迁移（results → dashboard → auth）。消 UX-12 且防再犯。

5. **公开分享页路由组化**（P1，S）：`/r/[token]` 移入无 Navbar/Footer/MasterWidget 的 layout（替代 DOM 手术）；loader 语言读 reading payload。消 UX-7。
6. **Golden Ripple 完成效果**（P2，S）：36 个 DOM ember → 单节点 CSS conic-gradient 边框扫光（GPU 便宜），保留印章 banner。消 UX-8。
7. **Quick wins**（每个 ≤1h）：删紫色 blob（UX-6）；首页 prompt 改为可点（打开 master 并预填文本）或删除（UX-5）；`export const viewport = { viewportFit: 'cover' }`（UX-14）；删除按钮升 touch-target（UX-9）；Theme 加 `system` 默认解析（UX-3）；海报渲染/分享接 `toast.promise`（UX-15）；补 `aria-label` 至图标按钮（UX-11）。
