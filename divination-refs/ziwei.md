# 紫微斗数基础 (Zi Wei Dou Shu)

## 重要提示：程序排盘 + AI 解盘模式

本系统使用 iztro 库进行程序化排盘，排盘结果（十二宫位、主星/辅星分布、四化飞星、大限等）由程序自动生成并已验证准确。
当用户消息中包含"程序预计算的紫微斗数命盘"数据时：
- **请直接使用程序提供的星耀和宫位数据，不要自行重新排盘**
- **你的角色是"解盘"而非"排盘"** — 基于准确的命盘数据进行深度分析
- 为每个宫位提供 analysis 字段的分析文本
- 重点分析四化飞星的影响、三方四正格局、大限走势

## 一、概述

紫微斗数是宋代陈希夷所创，以出生年月日时推算命盘，通过十四主星在十二宫的分布来论命。比八字更直观，宫位含义清晰，适合详细的人生各领域分析。

## 三、命宫确定方法

### 步骤一：找寅宫位置
- 紫微斗数以寅宫为起点（逆时针）
- 地支顺序：寅→卯→辰→巳→午→未→申→酉→戌→亥→子→丑

### 步骤二：由出生月定寅宫的天干
用**五虎遁年法**（与月柱起法相同）：

| 年干 | 寅宫天干 |
|-----|---------|
| 甲/己 | 丙寅 |
| 乙/庚 | 戊寅 |
| 丙/辛 | 庚寅 |
| 丁/壬 | 壬寅 |
| 戊/癸 | 甲寅 |

### 步骤三：由出生时辰定命宫
从**寅宫**开始，按出生月对应宫，再从该宫按时辰数（逆数），到达的宫位即为**命宫地支**。

**快捷公式：**
命宫地支 = (14 + 出生月 - 出生时辰对应数) mod 12
（时辰数：子=0, 丑=1, 寅=2...亥=11）

**更简便法（常用口诀）：**
> 寅宫起子时，顺数至生时，即为命宫位

从寅宫子时开始，顺时针（地支顺序）数到出生时辰，对应宫位为安命之宫，再从该宫逆数出生月数，停留宫位即命宫。

## 五、十四主星详解

### 紫微星系（七星）

**紫微星** ⭐⭐⭐⭐⭐
- 性质：帝王之星，土性
- 特质：尊贵威严，有领导力，自尊心强
- 命宫有紫微：有贵人相助，适合管理职位
- 缺点：孤高、难亲近

**天机星** ⭐⭐⭐⭐
- 性质：木性，机谋之星
- 特质：聪明机智，善谋划，反应快
- 适合：策划、顾问、研究

**太阳星** ⭐⭐⭐⭐⭐
- 性质：火性，光明之星
- 特质：开朗热情，无私奉献，男性气质强
- 女命有太阳：丈夫出色或多操心丈夫事

**武曲星** ⭐⭐⭐⭐
- 性质：金性，财帛之星
- 特质：果断刚毅，重实际，理财能力强
- 适合：财务、军警、硬件行业

**天同星** ⭐⭐⭐⭐
- 性质：水性，福德之星
- 特质：温和善良，重感情，享受生活
- 缺点：懒散、缺乏斗志

**廉贞星** ⭐⭐⭐
- 性质：火性，囚星/次桃花星
- 特质：热情、有才华，但感情复杂
- 缺点：多是非口舌

### 天府星系（七星）

**天府星** ⭐⭐⭐⭐⭐
- 性质：土性，财库之星
- 特质：稳重保守，积蓄财富，有容纳力
- 命宫有天府：财源稳定，晚年享福

**太阴星** ⭐⭐⭐⭐
- 性质：水性，田宅之星/女性之星
- 特质：细腻温柔，重美感，财帛丰厚
- 男命：妻贤内助；女命：美丽聪慧

**贪狼星** ⭐⭐⭐
- 性质：木性，桃花星/多欲之星
- 特质：多才多艺，欲望强，社交能力好
- 缺点：贪婪，感情复杂

**巨门星** ⭐⭐⭐
- 性质：水性，暗星/口才之星
- 特质：口才好，善辩，但多是非
- 适合：律师、演说、销售

**天相星** ⭐⭐⭐⭐
- 性质：水性，印星/辅助之星
- 特质：正直，有原则，善辅助
- 适合：幕僚、行政、文职

**天梁星** ⭐⭐⭐⭐
- 性质：土性，荫星/寿星
- 特质：老成持重，有长者风范，救人济世
- 适合：医疗、社工、宗教

**七杀星** ⭐⭐⭐
- 性质：金性，将星
- 特质：果断冲动，独立，开拓力强
- 缺点：性格急躁，多波折

**破军星** ⭐⭐⭐
- 性质：水性，破星/耗星
- 特质：改革创新，敢于冲破传统
- 缺点：破坏性强，耗损大

## 七、四化飞星

四化是紫微斗数最重要的分析工具，由**年干**决定：

| 年干 | 化禄 | 化权 | 化科 | 化忌 |
|-----|-----|-----|-----|-----|
| 甲 | 廉贞 | 破军 | 武曲 | 太阳 |
| 乙 | 天机 | 天梁 | 紫微 | 太阴 |
| 丙 | 天同 | 天机 | 文昌 | 廉贞 |
| 丁 | 太阴 | 天同 | 天机 | 巨门 |
| 戊 | 贪狼 | 太阴 | 右弼 | 天机 |
| 己 | 武曲 | 贪狼 | 天梁 | 文曲 |
| 庚 | 太阳 | 武曲 | 太阴 | 天同 |
| 辛 | 巨门 | 太阳 | 文曲 | 文昌 |
| 壬 | 天梁 | 紫微 | 左辅 | 武曲 |
| 癸 | 破军 | 巨门 | 太阴 | 贪狼 |

### 四化含义
- **化禄**（🟢）：财禄、顺利、增益，该星所在宫位事项顺遂
- **化权**（🔵）：权力、主导、掌控，该星所在宫位事项有主动权
- **化科**（🟡）：名声、文凭、贵气，利考试名誉
- **化忌**（🔴）：阻碍、破坏、损耗，该星所在宫位事项多波折

### 飞化应用（本命盘四化）
1. 确定本命年干（如1988年戊辰 → 年干戊）
2. 戊干：贪狼化禄、太阴化权、右弼化科、天机化忌
3. 查这四星落在命盘哪个宫位
4. 贪狼落官禄宫+化禄 → 事业顺遂有财
5. 天机落疾厄宫+化忌 → 健康需注意神经系统

## 八、大限与流年（斗数版）

### 大限
- 每10年一个大限宫
- 起大限方向：
  - **阳男阴女**：从命宫顺时针（地支顺序）走
  - **阴男阳女**：从命宫逆时针走
- 年龄分配：通常命宫大限为1-10岁，然后每移一宫+10年

### 流年
- 以每年的地支对应命盘宫位
- 流年太岁（该年地支所在宫）：该宫事项活跃

## 九、常见格局与断命要点

### 贵格
- **紫府同宫**（紫微+天府）：极贵之格
- **日月并明**（太阳+太阴于命/财）：文武双全
- **机月同梁**：宜从事文职、服务业
- **杀破狼格**（七杀/破军/贪狼坐命）：白手起家，适合商界

### 凶格
- **羊陀夹命**：擎羊和陀罗夹命宫 → 刑克多磨
- **空劫夹命**：地空地劫夹命宫 → 孤贫
- **火铃夹命**：火星铃星夹命宫 → 多灾

### 断命要点顺序
1. **看命宫主星**：定基本性格和格局高低
2. **看三方四正**（命宫+财帛+官禄+迁移）：命运整体走势
3. **看六吉六煞**分布：吉星多则助力大
4. **看四化**：化禄吉，化忌凶
5. **看大限**：该期间哪些星活跃
6. **看流年**：该年太岁所在宫位与四化

## 十、实用分析示例

**问：此人事业如何？**

分析步骤：
1. 找官禄宫（事业宫）主星
2. 看官禄宫三方（财帛、迁移）有无吉星会照
3. 看官禄宫有无四化（化禄/权吉，化忌凶）
4. 看大限是否走到官禄宫或其三方
5. 流年官禄宫状况

**结论示例：**
"官禄宫武曲化权，三方有紫微会照，事业格局高，有实权。大限走财帛宫，财运配合事业，正是发展高峰期。流年天机化忌入官禄，该年事业有变动，宜主动应对而非被动。"
