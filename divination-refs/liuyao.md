## 执行规则

### 禁止行为
- ❌ 不要重新排卦——程序数据为准
- ❌ 不要输出空泛套话："顺其自然"、"静待时机"
- ❌ 不要回避凶险信息——如实分析，但给出化解建议
- ❌ 不要忽略变爻——变爻是断卦关键

### 必须做到
- ✅ 先确定用神（根据所问之事）
- ✅ 分析用神旺衰（得月令否、得日建否、动静、变化）
- ✅ 判断原神、忌神、仇神的状态
- ✅ 结合世应关系断事
- ✅ 给出具体应期

## 断卦核心步骤

### 一、确定用神

根据所问之事确定用神：

| 所问之事 | 用神 |
|---------|------|
| 父母、文书、证件、房屋、学业 | 父母爻 |
| 兄弟、朋友、竞争对手 | 兄弟爻 |
| 子女、下属、快乐、解忧 | 子孙爻 |
| 妻子、财物、薪资、利润 | 妻财爻 |
| 丈夫、上司、官职、疾病、诉讼 | 官鬼爻 |
| 自身状态 | 世爻 |
| 对方（人/事/物） | 应爻 |

### 二、判断用神旺衰

**旺相标准：**
- 得月令生扶 → 旺
- 得日建生扶 → 相
- 动爻生之 → 有力
- 发动化回头生 → 增力

**衰弱标准：**
- 月令克制 → 受制
- 日建克制 → 被压
- 动爻克之 → 受伤
- 发动化回头克 → 大凶
- 空亡/入墓 → 暂无力

### 三、六亲生克关系

| 关系 | 生克 | 含义 |
|-----|------|------|
| 原神 | 生用神者 | 用神的助力来源 |
| 忌神 | 克用神者 | 用神的阻碍 |
| 仇神 | 生忌神者 | 间接伤害用神 |
| 用神 | 所取之爻 | 核心判断依据 |

**五行生克：**
- 木→火→土→金→水→木（相生）
- 木→土→水→火→金→木（相克）

### 四、世应分析

- **世爻** = 求卦人自己
- **应爻** = 所问对象（对方、事物）
- 世应相生 → 双方和谐，事可成
- 世应相克 → 有矛盾冲突
- 世爻旺 → 求卦人处主动
- 应爻旺 → 对方强势
- 世爻空亡 → 求卦人心意不定
- 应爻空亡 → 对方虚假或缺席

### 五、变卦分析

变爻规则：
- 老阳(9) → 变阴：阳极转阴，事物转折
- 老阴(6) → 变阳：阴极转阳，否极泰来

变卦判断：
- 变卦 = 事物最终趋势/结果
- 用神化进神 → 事越来越好
- 用神化退神 → 事越来越差
- 用神化绝 → 事物终结
- 用神化回头生 → 起死回生
- 用神化回头克 → 雪上加霜

### 六、应期判断

| 用神状态 | 应期 |
|---------|------|
| 用神旺而受制 | 制神被合/冲之时 |
| 用神衰而得生 | 生神旺相之时 |
| 用神入墓 | 冲墓之时 |
| 用神逢空 | 出空之时（过了空亡期） |
| 用神旺动 | 合住用神之时（合处逢冲） |
| 用神休囚 | 值日/值月旺相之时 |

应期一般以地支论：
- 近期：以日论（用神所临地支日、冲合日）
- 中期：以月论
- 远期：以年论

## 特殊规则

### 六冲卦（凶）
本卦六爻全冲 → 事散人离，不宜合作求财
（乾、坎、离、震、巽、坤、艮、兑八纯卦即六冲卦）

### 六合卦（吉）
本卦六爻全合 → 事成人和，利于合作

### 伏神
如果卦中无用神 → 需看伏神
伏神有力且能出现 → 事可成（需等待）
伏神无力 → 事难成

### 日月建
- 月建 = 当月地支，影响力持续整月
- 日建 = 当日地支，影响力仅当日但力量最强
- 月破（被月建冲）→ 该爻本月无力
