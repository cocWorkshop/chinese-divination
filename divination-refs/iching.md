# 易经八卦详解 (I Ching / Yi Jing)

## 一、基础概念

### 阴阳与爻
- **阳爻（—）**：实线，代表阳、刚、动、天
- **阴爻（--）**：虚线，代表阴、柔、静、地
- **爻**：卦的基本单位，六爻组成一卦
- 从下往上数：初爻、二爻、三爻、四爻、五爻、上爻

### 八卦（三爻卦）基础

| 卦名 | 符号 | 自然 | 方位 | 五行 | 家庭 | 身体 | 特性 |
|-----|-----|-----|-----|-----|-----|-----|-----|
| 乾 ☰ | 三阳 | 天 | 西北 | 金 | 父 | 首 | 健、刚 |
| 坤 ☷ | 三阴 | 地 | 西南 | 土 | 母 | 腹 | 顺、柔 |
| 震 ☳ | 下阳 | 雷 | 东 | 木 | 长男 | 足 | 动、进 |
| 巽 ☴ | 下阴 | 风 | 东南 | 木 | 长女 | 股 | 入、顺 |
| 坎 ☵ | 中阳 | 水 | 北 | 水 | 中男 | 耳 | 险、陷 |

### 先天八卦（伏羲八卦）方位
乾南、坤北、离东、坎西、震东北、巽西南、艮西北、兑东南

坎北、离南、震东、兑西、乾西北、坤西南、艮东北、巽东南（常用于风水）

## 二、起卦方法

### 铜钱法（三枚铜钱）

**材料：** 三枚铜钱（古钱最佳，现代硬币亦可）

**步骤：**
1. 静心，明确所问之事
2. 将三枚铜钱握于双手，专注问题
3. 摇动后抛出，记录结果
4. 正面（字）= 阳 = 3分；反面（花）= 阴 = 2分
5. 三枚总分：
   - **6分**（三阴）= 老阴 = 变爻（阴变阳）→ ×
   - **7分**（二阴一阳）= 少阳 = 不变 → ○
   - **8分**（一阴二阳）= 少阴 = 不变 → ●
   - **9分**（三阳）= 老阳 = 变爻（阳变阴）→ ⊙
6. 连摇六次，从下（初爻）到上（上爻）记录
7. 有变爻则产生**变卦**

**示例：**
```
第六次（上爻）：7 → 少阳 → 阳爻 —
第五次（五爻）：8 → 少阴 → 阴爻 --
第四次（四爻）：9 → 老阳 → 阳爻（变）⊙
第三次（三爻）：7 → 少阳 → 阳爻 —
第二次（二爻）：8 → 少阴 → 阴爻 --
第一次（初爻）：6 → 老阴 → 阴爻（变）×
→ 本卦 + 变卦（初爻阴变阳，四爻阳变阴）
```

### 数字起卦法（梅花易数简化）
1. 取两组数字（时间/随机数）
2. 上卦 = 第一数 ÷ 8 取余（余0则为8）
3. 下卦 = 第二数 ÷ 8 取余
4. 动爻 = 两数之和 ÷ 6 取余

### 时间起卦法
- 年数 + 月数 + 日数 ÷ 8 = 上卦余数
- 年数 + 月数 + 日数 + 时辰数 ÷ 8 = 下卦余数
- 年月日时之和 ÷ 6 = 动爻

## 三、六十四卦详解

### 上经（30卦）

**01. 乾卦 ䷀（乾上乾下）**
- 象：天行健，君子以自强不息
- 含义：纯阳极盛，大吉之卦；事业鼎盛，但需防刚极则折
- 六爻：潜龙→见龙→君子→跃龙→飞龙→亢龙
- 应用：仕途、创业极佳；感情防过于强势

**02. 坤卦 ䷁（坤上坤下）**
- 象：地势坤，君子以厚德载物
- 含义：纯阴，顺承之卦；适合辅助而非主导，利女性
- 应用：合伙、辅助事业佳；感情需主动

**03. 屯卦 ䷂（坎上震下）**
- 含义：草木初生，多艰难；万事开头难，需坚持
- 应用：创业初期多阻碍，需人扶助

**04. 蒙卦 ䷃（艮上坎下）**
- 含义：启蒙教育；需求师问道，不可莽撞
- 应用：学业、求知问卜

**05. 需卦 ䷄（坎上乾下）**
- 含义：等待时机；有雨将至，需耐心
- 应用：事业需等待，不可急进

**06. 讼卦 ䷅（乾上坎下）**
- 含义：争讼、口舌；不利诉讼，宜和解
- 应用：纠纷宜调解，勿争

**07. 师卦 ䷆（坤上坎下）**
- 含义：军队、纪律；需统一指挥，能成大事
- 应用：团队管理、竞争

**08. 比卦 ䷇（坎上坤下）**
- 含义：亲比、联合；利合作，有贵人
- 应用：合伙、结盟吉

**09. 小畜卦 ䷈（巽上乾下）**
- 含义：小有积蓄；积少成多，暂时受阻
- 应用：积累阶段，勿求大

**10. 履卦 ䷉（乾上兑下）**
- 含义：踩踏虎尾，谨慎行事
- 应用：危险中谨慎可脱险

**11. 泰卦 ䷊（坤上乾下）**

**12. 否卦 ䷋（乾上坤下）**

- 应用：诸事不顺，需守成待变

**13. 同人卦 ䷌（乾上离下）**
- 含义：与人同心，团结合作
- 应用：合作、朋友关系佳

**14. 大有卦 ䷍（离上乾下）**
- 含义：大有所获；丰收富足
- 应用：财运极佳，事业有成

**15. 谦卦 ䷎（坤上艮下）**

**16. 豫卦 ䷏（震上坤下）**

**17. 随卦 ䷐（兑上震下）**

## 四、爻位含义与解读

### 六爻对应
- **初爻**：事物开始，地位低微，民间、基层
- **二爻**：臣下之位，多吉（得中），努力发展期
- **三爻**：内卦之顶，多凶（不中不正），过渡期
- **四爻**：近君之位，多惧，高层谋臣
- **五爻**：君位，最尊贵，大吉（得中）
- **上爻**：穷极之位，过犹不及，退休老人

### 爻的"当位"与"不当位"
- **当位（正）**：阳爻居阳位（初三五），阴爻居阴位（二四上）→ 正确
- **不当位（不正）**：阳居阴位或阴居阳位 → 偏差
- **得中**：居二爻或五爻 → 中道，较吉

### 变爻解读原则
1. **无变爻**：看本卦卦辞
2. **一个变爻**：看本卦该爻爻辞
3. **两个变爻**：看本卦两变爻，以上爻为主
4. **三个变爻**：看本卦卦辞和变卦卦辞各半
5. **四个变爻**：看变卦卦辞，以不变的两爻为参考
6. **五个变爻**：看变卦卦辞
7. **六个变爻**：乾坤卦看特殊爻辞，其余看变卦卦辞

## 五、断卦基本方法

### 步骤
1. **起卦** → 确定本卦与变卦
2. **定主题** → 明确所问何事
3. **找用神** → 确定问题对应的爻（如问财找财爻）
4. **看旺衰** → 用神得令则旺，失令则衰
5. **看六亲** → 各爻的生克关系
6. **看变化** → 变爻带来的转化
7. **综合判断** → 给出吉凶结论

### 六亲（六神）体系（纳甲法）
每卦六爻配以五行六亲：
- **父母爻**：长辈、上司、文书、房屋
- **兄弟爻**：兄弟、朋友、竞争者（多耗财）
- **子孙爻**：子女、下属、快乐、克官
- **妻财爻**：妻子、财富、动产
- **官鬼爻**：官职、丈夫、疾病、压力

### 卦象解读要点
- **旺相休囚死**：用神在所占月日的五行状态
- **生克冲合**：各爻间的相互作用
- **日月动爻**：月令日辰和动爻对用神的影响

## 六、实用断卦示例

### 问工作晋升
- **用神**：官鬼爻（代表职位）
- **官鬼旺**：升迁可能大
- **子孙动克官**：不利晋升
- **财爻动生官**：通过努力获得晋升

### 问感情婚姻
- **男问女**：妻财爻为用神
- **女问男**：官鬼爻为用神
- **用神旺相有气**：感情顺利
- **用神空亡**：对方心不在此

### 问财运
- **用神**：妻财爻
- **财爻旺动**：财运佳
- **兄弟动克财**：破财防小人
- **父母动**：文书之财（工资、遗产）

### 问疾病
- **用神**：看世爻和六冲
- **子孙爻**为医药，能克官鬼（病邪）
- **子孙旺动**：疾病易治
- **官鬼旺克世**：病情较重
