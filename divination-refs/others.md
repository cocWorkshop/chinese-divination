# 梅花易数与六壬神课 (Mei Hua Yi Shu & Liu Ren)

---

# 第一部分：梅花易数

## 一、概述

梅花易数是宋代邵雍所创，以观察事物的数量、方位、时间来起卦，核心思想是"万物皆有数，数中有卦象"。特点是随机灵活，不需工具，适合日常占卜。

---

## 二、起卦方法

### 时间起卦法（年月日时）

1. **起上卦**：将年月日数字相加 ÷ 8，余数为上卦
2. **起下卦**：将年月日时数字相加 ÷ 8，余数为下卦
3. **起动爻**：年月日时总和 ÷ 6，余数为动爻（从下往上数）

**数字对应卦：**
1=乾 2=兑 3=离 4=震 5=巽 6=坎 7=艮 8=坤（余0则取8）

**示例：**
2024年3月15日午时（12）
- 年数：2024后两位=24 → 2+4=6（或直接用年干地支数）
- 简化：年=6（甲辰年，辰=5），月=3，日=15，时=7（午）
- 上卦：(6+3+15) ÷ 8 = 24÷8 余0 → 8 = 坤
- 下卦：(6+3+15+7) ÷ 8 = 31÷8 余7 = 艮
- 动爻：(6+3+15+7) ÷ 6 = 31÷6 余1 = 初爻动
- 本卦：坤上艮下 = 谦卦（15），初爻动
- 变卦：初爻变 → 坤上震下 = 豫卦（16）

### 数字起卦法

任何可用的数字：
- 报纸数字、街牌号、随机抽数
- 单数：上卦数；双数：下卦+动爻
- 三个数字：第一数上卦，第二数下卦，第三数动爻

### 方位起卦法
- 看到物体的方位（东南西北）对应卦
- 东=震(4)，东南=巽(5)，南=离(3)，西南=坤(8)
- 西=兑(2)，西北=乾(1)，北=坎(6)，东北=艮(7)

### 物象起卦法
观察周围事物的数量和特征：
- 树木、草花数量 → 起卦数
- 声音次数 → 动爻数

## 三、体用卦判断

### 体卦与用卦
- **体卦**：代表占卜者本人，是判断吉凶的主体
- **用卦**：代表所问事物，是变化的客体

### 体卦确定（以动爻所在卦为准）
- 动爻在上卦 → 上卦为用卦，下卦为体卦
- 动爻在下卦 → 下卦为用卦，上卦为体卦

### 生克关系
- **用生体**：所问之事对我有利（大吉）
- **体生用**：我付出较多，耗费精力（中等）
- **体克用**：我能控制局势，主动（较吉）
- **用克体**：事情对我不利，受压制（凶）
- **体用比和**：五行相同，平稳无大变化

## 四、五行生克判断

### 卦象五行
| 卦 | 五行 |
|----|-----|
| 乾兑 | 金 |
| 坤艮 | 土 |
| 震巽 | 木 |
| 坎 | 水 |
| 离 | 火 |

### 月令影响
以占卜时的月份判断体用卦旺衰：
- 春（寅卯月）：木旺→震巽旺；火相；土休；金囚；水死
- 夏（巳午月）：火旺；土相；金休；水囚；木死
- 秋（申酉月）：金旺；水相；木休；火囚；土死（此处简化）
- 冬（亥子月）：水旺；木相；火休；土囚；金死

---

## 五、互卦与变卦

### 互卦（内在变化）
取二三四爻为新下卦，三四五爻为新上卦：
- 六爻卦 → 取中间四爻组成互卦
- 互卦反映事物中期发展

### 变卦（最终结果）
动爻变化后得到的新卦，代表事情最终走向。

### 解卦顺序
1. 本卦（现状）
2. 互卦（中期）
3. 变卦（结果）
4. 体用生克（主观吉凶）

---

## 六、断卦实用技巧

### 观象取意
梅花易数强调卦象的物象联想：
- 乾：天、圆、头、父、君、金属、马
- 坤：地、方、腹、母、众、布帛、牛
- 震：雷、动、长男、足、竹、车
- 巽：风、入、长女、股、木、鸡
- 坎：水、陷、中男、耳、酒、猪
- 离：火、明、中女、目、书、雉
- 艮：山、止、少男、手、门、犬
- 兑：泽、悦、少女、口、金、羊

### 应期判断
用爻变化判断事情发生时间：
- **克应**（用克体）：近期，约以旬数
- **生应**（用生体）：较远，以月数
- **五行旺月**：该五行旺盛时应验
- **三合、六合之年月日**：应验时间

## 七、实用示例

**问：此次求职能否成功？**

起卦（假设）：
- 本卦：天水讼（乾上坎下），五爻动
- 互卦：坎上离下 = 既济
- 变卦：五爻变阴 → 天火同人

分析：
- 动爻在上卦（乾）→ 乾为用，坎为体
- 体（坎水）用（乾金）→ 金生水，用生体 → 大吉
- 本卦讼：有争执，过程不顺，但五爻为君位，变爻有力
- 变卦同人：同心协力，最终和谐
- 月令：若在秋月（金旺），乾金更强，用生体力量更大
- **结论**：求职有竞争，过程有波折，但最终成功，五爻动说明有高层支持

# 第二部分：六壬神课

## 一、概述

六壬是三式（太乙、奇门、六壬）之一，以十二天将、四课三传为核心，判断事情吉凶。六壬预测细腻，适合具体事件的详细分析。

---

## 二、基础概念

### 天干地支与六壬
六壬以**壬**（水）为宗，取天一生水之意，以十二地支流转为骨架。

### 十二月将（天盘）
每月对应一个月将，月将是六壬布局的关键：

| 月将 | 对应节气起始 | 地支 |
|-----|-----------|-----|
| 登明 | 雨水后 | 亥 |
| 河魁 | 春分后 | 戌 |
| 从魁 | 谷雨后 | 酉 |
| 传送 | 小满后 | 申 |
| 小吉 | 夏至后 | 未 |
| 胜光 | 大暑后 | 午 |
| 太一 | 处暑后 | 巳 |
| 天罡 | 秋分后 | 辰 |
| 太冲 | 霜降后 | 卯 |
| 功曹 | 冬至后 | 寅 |
| 大吉 | 大寒后 | 丑 |
| 神后 | 雨水前（小寒后）| 子 |

### 十二天将（神将）

| 天将 | 五行 | 阴阳 | 主事 |
|-----|-----|-----|-----|
| 贵人 | 土 | 阴 | 贵人助力、逢凶化吉 |
| 螣蛇 | 火 | 阴 | 怪异、梦惊、虚惊 |
| 朱雀 | 火 | 阳 | 文书、口舌、官讼 |
| 六合 | 木 | 阴 | 婚姻、合同、暗谋 |
| 勾陈 | 土 | 阳 | 争斗、田土、官司 |
| 青龙 | 木 | 阳 | 财喜、贵人、吉祥 |
| 天空 | 土 | 阳 | 虚诈、口舌、空亡 |
| 白虎 | 金 | 阳 | 凶险、丧事、血光 |
| 太常 | 土 | 阴 | 饮食、衣服、吉事 |
| 玄武 | 水 | 阴 | 盗贼、阴私、奸情 |
| 太阴 | 金 | 阴 | 阴私、女性、隐秘 |
| 天后 | 水 | 阴 | 妇女、阴私、婚事 |

## 三、四课三传

### 四课结构

六壬布局以**日干**（占卜当日天干）为起点：

**起四课规则：**
- **第一课**：日干（天）上、日支（地）
- **第二课**：日支（天）上、日支地支
- **第三课**：第一课地盘、第三课上神
- **第四课**：第二课地盘、第四课上神

（具体需按完整布局规则操作）

### 三传（初传、中传、末传）

三传代表事情的：
- **初传（发用）**：事情的起始和原因
- **中传**：事情的发展过程
- **末传**：事情的最终结果

### 发用（初传）确定方法

有多种起法，常用的有：
1. **贼克法**：找四课中克日干或日支的上神
2. **比用法**：找与日干相比（同五行）的课
3. **涉害法**：多课同克时，找路途最深者

---

## 四、六壬断法基础

### 吉将与凶将

**吉将：** 青龙（财喜）、贵人（贵人助）、太常（享受）、六合（和合）
**凶将：** 白虎（血光）、螣蛇（惊扰）、勾陈（争斗）、玄武（盗贼）

### 常用断法口诀

- **贵人临日**：有贵人相助，逢凶化吉
- **青龙临财**：财运亨通
- **白虎临病**：病情较重，凶险
- **朱雀临文**：文书顺利，考试得利
- **玄武临财**：防钱财被盗或欺诈
- **螣蛇临宅**：家中有怪异、惊扰

### 事项对应天将

| 问事 | 主要看天将 |
|-----|---------|
| 婚姻 | 六合、天后、太阴 |
| 财运 | 青龙、太常 |
| 官司 | 朱雀、勾陈、贵人 |
| 疾病 | 白虎、玄武 |
| 出行 | 传送（申）、天空 |
| 考试 | 朱雀、贵人 |
| 失物 | 玄武（寻盗）|

---

## 五、六壬与时间预测

### 应验时间判断
- **天将的五行旺月**：该天将主事时间
- **三传干支**：对应年月日
- 青龙（木）→ 春季应；白虎（金）→ 秋季应

### 六壬择日
根据当时月将和贵人所在方位选择吉时：
- 贵人在某时辰对应方位 → 该时辰出行吉利
- 青龙当值 → 财事吉祥

---

## 六、简单实例

**问：失物能否找回？（假设某日壬子日，雨水后月将亥）**

1. 布局：按壬子日，月将亥，确定十二地支分布
2. 找三传：初传看起因，末传看结果
3. 初传：玄武临子 → 盗贼、阴私之象，失物疑被盗
4. 末传：贵人临亥 → 有人相助，有望找回
5. 中传：太阴临戌 → 隐秘处，需在隐蔽地方寻找
6. **结论：** 物品可能被人顺手拿走，在某隐蔽处，最终有望找回。建议在[方位]附近寻找。

## 七、学习建议

六壬是三式中最复杂的，建议：
1. 先掌握十二天将的基本含义
2. 学会看天将与事项的对应
3. 理解四课三传的逻辑顺序
4. 参考经典：《大六壬指南》《六壬大全》

梅花易数则相对简单，先掌握体用卦生克，再逐步深入卦象象意。
参考经典：《梅花易数》（邵雍著）、《增删卜易》（为六爻体系，与梅花有所区别）
