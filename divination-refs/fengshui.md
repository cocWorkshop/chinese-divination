# 风水核心理论 (Feng Shui)

## 一、风水概述

风水（堪舆学）是研究环境对人产生影响的学问，核心是"藏风聚气"。
- **形势派**：注重山水形态、地形地貌
- **理气派**：注重方位、时间、数理计算

---

## 二、形势派基础

### 四兽（四灵）理论
理想地形：
- **玄武**（后山）：北方靠山，需高厚
- **朱雀**（前方）：南方开阔，明堂宽广
- **青龙**（左山）：东方山脉，宜略高
- **白虎**（右山）：西方山脉，宜略低

口诀：**"左青龙，右白虎，前朱雀，后玄武"**

### 形局吉凶
- **环抱有情**：山水环绕，气聚不散 → 吉
- **反弓煞**：河流反弓背对 → 凶
- **冲射煞**：道路、河流直射门口 → 凶
- **天斩煞**：两栋高楼之间的缝隙 → 凶
- **壁刀煞**：建筑边角正对门窗 → 凶

### 水法基础
- **来水有情**：水向屋流、环绕 → 聚财
- **去水无情**：水直流而去 → 破财
- **三叉水**（水流三岔口）：凶
- **聚水**（内明堂有水）：财聚

## 三、理气派 — 八宅理论

### 八宅法基础
根据**坐山**（房屋背靠方向）确定宅卦，再结合**命卦**论吉凶。

### 宅卦八方吉凶

**以坐山判断宅卦：**

| 坐山 | 宅卦 | 派别 |
|-----|-----|-----|
| 坐北朝南（坎宅） | 坎 | 东四宅 |
| 坐西南朝东北（坤宅） | 坤 | 西四宅 |
| 坐东朝西（震宅） | 震 | 东四宅 |
| 坐东南朝西北（巽宅） | 巽 | 东四宅 |
| 坐西北朝东南（乾宅） | 乾 | 西四宅 |
| 坐西朝东（兑宅） | 兑 | 西四宅 |
| 坐东北朝西南（艮宅） | 艮 | 西四宅 |
| 坐南朝北（离宅） | 离 | 东四宅 |

**东四宅**（坎震巽离）：适合东四命人
**西四宅**（乾坤艮兑）：适合西四命人

### 八宅四吉四凶方

以**坎宅**为例（坐北朝南）：

| 方位 | 名称 | 吉凶 | 含义 |
|-----|-----|-----|-----|
| 南方 | 延年 | 吉 | 婚姻、健康 |
| 东方 | 天医 | 吉 | 健康、财运 |
| 东南 | 生气 | 大吉 | 财运、子嗣 |
| 北方（坐） | 伏位 | 小吉 | 稳固 |
| 西南 | 祸害 | 小凶 | 小病小灾 |
| 西北 | 六煞 | 凶 | 桃花、漏财 |
| 西方 | 五鬼 | 大凶 | 官非、疾病 |
| 东北 | 绝命 | 大凶 | 绝嗣、重病 |

### 个人命卦计算

**男命卦公式：**
命卦数 = 11 - (出生年后两位数字之和，若超两位再加) = 最终个位数
- 例：1988年出生 → 8+8=16 → 1+6=7 → 11-7=4 → 命卦=4=**巽** → 东四命

**女命卦公式：**
命卦数 = 出生年后两位数字和 + 5（若超两位再加，若得5则为2坤）
- 例：1990年出生 → 9+0=9 → 9+5=14 → 1+4=5 → 5归坤 → 命卦=2=**坤** → 西四命

**命卦与宅卦对应：**
- 东四命（坎1/离9/震3/巽4）住东四宅 → 吉
- 西四命（乾6/坤2/兑7/艮8）住西四宅 → 吉
- 东四命住西四宅，或西四命住东四宅 → 不协调

### 五（中宫）的处理
- 男命中宫5归坤2
- 女命中宫5归艮8

## 四、飞星派基础（玄空飞星）

### 概述
飞星派（玄空学）是最精细的理气派，结合**建筑建造年份**（运盘）和**坐向方位**（向盘、坐盘）形成飞星盘，分析空间磁场。

### 三元九运
- 每60年为一元，分上中下三元
- 每元20年，共九运
- 当前：**八运（2004-2023）**，**九运（2024-2043）**

### 洛书飞星顺序

**阳顺（顺飞）：**
```
从5中宫出发：5→6→7→8→9→1→2→3→4→5
```
顺序飞布：中→西北→西→东北→南→北→西南→东→东南→中

**九宫飞星图（上山下水示例）：**
以坐北朝南的宅子，八运盘为例，具体需专业软件计算。

### 飞星组合吉凶（主要）
- **旺星到门/房**：当运旺星（如八运的8）到门口 → 大吉旺财
- **山星旺向星旺**：双星到旺 → 人丁财运双旺
- **五黄**（5）入中 → 凶，需化解
- **二黑**（2）主病 → 需注意疾病
- **七赤**（7）主盗贼、口舌（七运后退气）
- **三碧**（3）主争斗、官非
- **九紫**（9）主喜庆、火灾（九运时为旺星）

### 流年飞星
每年太岁星飞入各宫，带来流年影响：
- **流年五黄**所在方位：凶，不宜动土、装修
- **流年二黑**所在方位：主疾病，注意健康
- **流年八白**：财星，此方位宜开门放光

## 六、居家风水实用要点

### 大门
- 门对门（两门相对）：口舌是非
- 门对走廊尽头：气场直冲
- 大门对镜子：气被反射出去
- **化解**：屏风、门帘、绿植

### 客厅
- 沙发靠实墙：有靠山
- 电视对沙发：不宜正对窗
- 鱼缸位置：财位（八宅或飞星旺财位）

### 卧室
- 床头靠实墙：安全感，睡眠好
- 床对镜子：影响睡眠、感情
- 床对门或横梁压床：凶
- 卫生间门对床：健康不佳

### 厨房
- 灶台靠窗：漏财
- 水槽紧邻灶台：水火相克（需隔开）
- 灶台对门：家人健康受影响

### 卫生间
- 位置宜在宅中凶位（绝命、五鬼等方）
- 不宜在宅中中央：压中宫，不利全家
- 门宜常关

## 八、分析流程

1. **确定坐向**：用指南针测量
2. **建造年份**：确定所在运（目前九运2024+）
3. **排飞星盘**：专业软件或手动计算
4. **标注八宅**：按坐山确定四吉四凶位
5. **现状核对**：门、主卧、厨灶在哪个方位
6. **流年加持**：叠加当年飞星
7. **综合建议**：哪些方位需增强，哪些需化解
